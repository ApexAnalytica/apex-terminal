### SVG font bug — 2026-05-02

**Symptom:** Text inside SVG visuals (EngineFlow, EngineGraph,
OmegaRadar) was rendering in Times instead of Geist Mono. **Cause:**
`var(--font-mono)` was defined inside Tailwind v4's `@theme inline { ... }`
block, which emits at `:root` but the inner reference (`var(--font-geist-mono)`)
is only set on `<body>` via Next.js's font className. The chain doesn't
resolve when computed at `:root`. **Fix:** Replaced all
`var(--font-mono)` with `var(--font-geist-mono)` directly in SVG text
attributes. `var(--font-michroma)` works fine because Next.js sets it
directly on body. **Don't repeat:** when adding new SVG visuals, use
`var(--font-geist-mono)` and `var(--font-michroma)` directly — never
`var(--font-mono)` or `var(--font-sans)`.
